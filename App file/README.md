# Store Management App

## Overview
The **Store Management App** is a user-friendly software solution designed to help local businesses streamline their operations. It enables efficient management of sales, inventory, customers, and activities through a clean and intuitive graphical user interface (GUI). Whether you run a grocery store, pharmacy, or boutique, this app is tailored to meet your needs.

---

## Features

### 1. **Cart System**
- Add customer details (name, phone number) and selected products to the cart.
- Automatically generates professional invoices in DOCX format.
- Calculates totals and manages payments seamlessly.

### 2. **Product Management**
- Add new products and update stock levels.
- Edit or delete product details as needed.
- Multi-select products for bulk deletion.

### 3. **Customer Management**
- View a list of previous customers and their purchase history.
- Search by customer name, ID, or filter by date.

### 4. **Sales Tracking**
- Access a detailed list of sold products.
- Search by product name or product ID.
- Analyze sales trends to identify best-sellers.

### 5. **Activity Monitoring**
- Track all actions performed within the app, such as:
  - Adding or editing products.
  - Deleting items from the database.
  - Sales and stock updates.
- View activity logs for better control and accountability.

## Technologies Used
- **Programming Language:** Python
- **GUI Framework:** Tkinter
- **Database:** SQLite/MySQL
- **Document Generation:** `python-docx`

## Installation

### Prerequisites
- Python 3.8 or higher
- Required Python libraries:
  ```bash
  pip install tkinter mysql-connector-python python-docx
  ```

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/store-management-app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd store-management-app
   ```
3. Run the application:
   ```bash
   python main.py
   ```

---

## Usage
1. Launch the app by running `main.py`.
2. Navigate through the menu options to:
   - Add or manage products.
   - Process sales and generate invoices.
   - View customer and sales records.
   - Monitor activities for insights.
